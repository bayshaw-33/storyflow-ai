# KIIKIS 战略白皮书设计

## 目标

重写现有 KIIKIS 白皮书，生成一份面向产业合作方、IP 权利方和重要外部沟通对象的中文版战略白皮书。新版必须清楚解释 KIIKIS 的 IP 资产体系、产品闭环、复利机制与商业方向，同时省略足以帮助第三方复刻产品的专有技术细节。

成品不是产品操作手册、商业计划书或技术尽调材料。它负责建立清晰的外部认知：KIIKIS 不只是调用生成模型的工具，而是一套让 IP 被定义、生产、继承、验证、授权和持续增值的 AI 原生资产系统。

## 核心定位

白皮书统一使用以下定位：

> KIIKIS 是 Universe-First 的 AI 原生 IP 资产与影视生产系统。它把故事世界、演员身份、内容生产、资产来源和未来授权连接为可持续积累的 IP 网络。

现阶段产品终点表述为“从剧本生成并组织可直接进入专业剪辑流程的镜头素材包”，不宣称已经完成自动剪辑、正式版权登记、自动确权或成熟的开放交易市场。

## 核心叙事

### 行业判断

生成模型能力会迅速普及，单次生成和模型接入不会形成长期壁垒。AI 内容生产的长期问题是资产碎片化、人物与世界观不一致、项目之间无法继承、生成过程不可追踪，以及作品完成后无法形成可持续复用和授权的 IP 资产。

### KIIKIS 的答案

KIIKIS 让一次创作成为下一次创作的资产基础。用户从 Universe 调用既有世界、角色、场景、道具和规则，完成剧本、分镜、关键帧和视频镜头生产；系统在用户无感的情况下保留版本、来源、选择、使用关系和关键生成事实；最终作品、角色形象和制作资产回流到 Universe，供后续作品继承。

### 五层 IP 资产体系

1. **IP 本体层**：Universe、世界规则、角色、场景、道具、关系与 Canon。
2. **身份与演绎层**：AI 演员、故事角色、选角关系、项目形象和视觉一致性。
3. **内容生产层**：小说、剧本、分镜、关键帧、视频镜头及其版本关系。
4. **来源与权利层**：创作者、素材来源、授权声明、修改历史、使用记录与证据包。
5. **价值流通层**：跨作品复用、团队共享、演员调用，以及未来的授权、交易和收益分配。

### 资产飞轮

白皮书使用一张高层飞轮图表达以下关系：

```text
Universe 更完整
→ 制作更快且一致性更高
→ 产生更多作品与项目资产
→ 留下更多来源、选择和使用关系
→ IP 更容易复用、合作与授权
→ 新成果继续增强 Universe
```

## 演员库表达

演员库不是普通的人物图片集合，而是独立于故事角色的可复用表演身份网络。

白皮书在概念层解释三层关系：

```text
Actor：可复用的 AI 演员身份
Character：Universe 中的故事角色
Portrayal：某位演员在某部作品中对角色的具体演绎
```

当前阶段说明：符合授权条件的 AI 演员可以在平台内共享，其他用户可将其用于自己的作品，并保留创建者和使用关系；使用者不能修改原始演员身份，只能创建属于本项目的角色形象。AI 生成演员可默认进入平台共享；真人照片需要明确确认肖像授权后才能共享。

未来方向说明：演员创建者可设置商业使用条件，平台记录调用、授权与作品关系，并在成熟阶段支持定价、支付和收益分配。白皮书不得将未来市场描述为已经上线。

## 留痕与证据表达

白皮书使用“无感创作留痕”和“一键制作证据包”，避免使用“自动确权”“版权证书”或“保证权属”等法律结论。

对外表述限于：

- 系统在关键制作节点记录版本、来源、操作者、使用资产和生成事实；
- 需要时可生成包含时间线、文件清单和完整性校验信息的制作证据包；
- 证据包可辅助合作、授权、尽调和争议处理，但不替代法律登记或权属裁定。

## 机密与披露边界

成品标记：

```text
KIIKIS Strategic Whitepaper
Confidential · Limited Distribution
本版本已省略专有技术与实施细节
```

白皮书不披露：

- 数据库表名、字段、Schema 与迁移结构；
- API 路径、请求契约和内部 ID；
- Prompt 模板、提示词拼装和一致性算法；
- 模型路由、Fallback、供应商配置和密钥管理；
- Hash 链、Manifest、幂等、状态机和原子发布实现；
- 存储路径、权限策略、RLS 细节和基础设施拓扑；
- 可直接还原产品实现的数据关系图；
- 代码量、内部日志、真实用户数据和未公开作品内容。

允许披露的技术能力限于高层结果：模型中立的生成编排、版本化 IP 资产图谱、可追溯的资产继承、演员与角色分离、默认创作留痕、私有证据包和未来授权记录。

## 商业表达

白皮书不编造用户数、收入、模型成本优势、市场规模、转化数据或其他未经核实的财务数据。没有可靠公开来源和项目负责人确认的数据不作为事实出现。

商业模式按阶段表达：

1. 内部与专业团队的生产工作台和模型使用服务；
2. 团队版 Universe、资产复用和协作能力；
3. AI 演员与 IP 资产的授权和交易服务；
4. 在权利、支付和治理能力成熟后形成平台服务收入。

不在白皮书中承诺具体价格、分成比例或上线日期。

## 视觉设计

- A4 竖版，中文版正文，关键概念保留英文副标题。
- 封面使用网站首页品牌主句“每一个宇宙，都始于一个念头。”；可在内页引用“都在一个宇宙里，由你来建造。”，但不把品牌主句改写成功能承诺。
- 采用深色电影工业风，主色为近黑、紫色和冷青色，避免延续旧版大面积空白的轻型 SaaS 风格。
- 封面与章节页强调 Universe、轨道、资产节点和电影帧的视觉语言。
- 使用高层关系图、生产闭环图、五层资产体系图和资产飞轮图，不使用可逆向工程的数据结构图。
- 正文保持短段落、强标题和留白；每页只传达一个核心观点。
- 页脚包含 KIIKIS、Limited Distribution 和页码。

## 准确性规则

- 所有功能按“当前已具备 / 正在建设 / 中长期方向”明确分层。
- 当前能力只以仓库代码、生产状态、验证记录和负责人确认的信息为依据。
- 不把已设计但未上线的能力写成既成事实。
- 不使用无法核实的市场数字。
- 不声称证据包自动产生法律权利。
- 不声称共享演员市场、定价、支付或分账已经上线。
