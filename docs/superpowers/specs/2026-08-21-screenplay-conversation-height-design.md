# 剧本工作台对话区高度修复设计

## 目标

修复剧本工作台 AI 对话内容挤在顶部、面板底部留下大块无效空白的问题，同时保持现有两栏结构、对话功能和视觉风格不变。

## 根因

`aiPanel` 是占满剩余视口高度的 Flex 容器，但 `main-view-conversation` 与 `main-view-diff` 包装层是普通块级元素，没有参与高度分配。包装层内的 `kkConversation` 因此只能按内容高度布局；外层 `aiPanel` 继续占满剩余空间，形成面板底部空白。

## 设计

- 对话视图和候选修改视图包装层必须成为可收缩的纵向 Flex 容器，并占满 `aiPanel` 的可用高度。
- `kkConversation` 继续纵向排列：对话记录区伸展并独立滚动；错误提示位于记录区与输入区之间；输入区固定在面板底部。
- 短对话时，新增空间归属于对话记录区，而不是落在输入区下方。
- 长对话时，只滚动对话记录区，不移动工作台顶部导航，也不把输入框推出视口。
- 文档视图继续使用原有编辑器布局，不受本次修复影响。

## 验收标准

1. `main-view-conversation` 和 `main-view-diff` 均建立完整的高度链。
2. 输入区是对话面板最后一个可见区域，其下不存在大块面板内空白。
3. 对话记录区拥有剩余高度并可独立滚动。
4. 错误提示和重试按钮仍显示在输入区上方。
5. 桌面与窄屏布局均不产生新的横向溢出。
6. 相关 UI 合约测试、TypeScript 检查和生产构建通过。

## 范围

仅修改剧本工作台对话视图的布局类与相应回归测试；不修改 API、数据库、会话内容、工作流阶段或其他工作台。
