# 音乐工作台产品化改造设计

## 背景

当前歌曲工作台顶部的“我的作品”“音色库”“工具箱”分别指向通用档案、配音/TTS 工作台和通用模板页，不能形成连续的歌曲创作流程。右侧已经展示完整的生成历史，因此顶部的“历史记录”按钮是重复入口。

本次改造将歌曲工作台统一命名为“音乐工作台”，并把三个入口收敛为歌曲专用能力。

## 已确认的产品决策

- “我的作品”只展示歌曲工作台产生的歌曲类作品，不混入剧本、美术、视频或通用制作档案。
- 歌曲类作品包含歌曲、纯音乐和音效生成结果，并在列表中通过类型标识区分。
- “音色库”是歌曲人声设定库，不是 TTS 音色库，也不新增语音克隆流程。
- 左侧保留两个动作，但明确层级：次按钮“聊一聊”，主按钮“生成内容文档”。
- 右侧主按钮负责实际音频生成，文案为“生成音频候选”。
- AI 重新生成内容时创建新的歌词/曲风/音效文档卡片；手动编辑只更新当前卡片。
- 移除右侧标题栏的“历史记录”按钮，保留下方的完整“生成历史”。
- 顶部产品名称、页面标题、可见文案和相关测试统一使用“音乐工作台”。

## 方案选择

采用渐进式产品化方案：复用现有歌曲项目、音频任务、签名下载、文档和歌手设定能力，新增歌曲专用页面与共享展示组件；不改变 Atlas Cloud 音乐生成协议，不接入 TTS，不引入与本次目标无关的全站资产中心。

这样可以保留现有生产链路，同时让三个入口具备明确且可验证的实际用途。

## 页面设计

### 1. 我的作品

入口使用新的歌曲作品库页面，避免继续把歌曲导航指向通用 `/archive`。

页面内容：

- 歌曲项目列表：标题、最近更新时间、歌曲类型、最近使用模型和生成状态。
- 音频结果列表：歌曲、纯音乐、音效分别标识；可播放和下载已入库文件。
- 筛选：全部、歌曲、纯音乐、音效；全部、生成中、已完成、失败。
- “继续创作”返回 `/song-workbench?projectId=...`。
- 空状态提供“开始创作”入口；加载、错误和无下载文件状态都给出明确操作。

数据来源优先使用已有项目库和 `/api/audio/jobs`，按当前登录用户过滤，不直接暴露 Provider URL。下载继续经过服务端签名下载接口。

### 2. 音色库

改造成歌曲人声设定库，沿用音乐工作台已有 `SingerProfile` 结构：

- 名称、性别/人声方向、声音质感、演唱方式。
- 安全提示词、禁止输出词、语言和备注。
- 新增、编辑、复制、删除。
- 一键应用到当前歌曲工作台，生成时只带入当前选中的设定。
- 纯音乐和音效模式不携带人声设定，避免无意加入 vocal。

默认歌手设定与已有歌曲工作台数据要兼容迁移；该页面不显示或生成 TTS 台词，不调用配音 Provider。

### 3. 工具箱

改造成歌曲专用工具页，第一版只放已有流程中能立即产生价值的工具：

- Suno V6 曲风提示词检查器：实时显示 UTF-8 字节数，超过 1000 字节时阻止复制/应用，并提供压缩提示。
- 纯音乐 / 音效提示词模板：模板包含禁止随机人声的约束，可复制到聊天或文档流程。
- 生成与下载健康检查：检查登录、模型能力、最近任务状态、文件是否已经入库和下载签名是否可用。
- 歌曲交付包入口：复用现有交付包生成，不另建一套导出协议。

### 4. 音乐工作台主界面

- 顶部名称统一为“音乐工作台”。
- 顶部导航保留“创作 / 我的作品 / 音色库 / 工具箱”。
- 移除右侧“历史记录”按钮。
- 左下角按钮显示为“聊一聊”和“生成内容文档”，其中“聊一聊”为次按钮。
- 右侧按钮显示为“生成音频候选”，只负责向 Atlas Cloud 提交实际音频任务。
- 保持参考图的暗色视觉、青绿色主操作色、清晰的 32/68 工作区比例和移动端切换。

## 数据与安全边界

- 所有歌曲项目和音频任务按当前用户隔离。
- 作品库展示的是歌曲工作流数据，不复用通用创作档案页面的混合数据。
- 音频播放可使用短期签名 URL；下载必须经过现有服务端下载接口。
- 失败任务显示真实失败状态和重试入口，不把 Provider URL 当作永久文件地址。
- 纯音乐/音效请求不发送歌词，也不发送歌曲人声设定。

## 验收标准

- 顶部和页面标题中不再出现“歌曲工作台”，统一为“音乐工作台”。
- “历史记录”按钮从音乐工作台标题区消失，下方生成历史仍完整可用。
- “我的作品”只显示歌曲工作流内容，并能打开、播放、下载已完成音频。
- “音色库”能管理歌曲人声设定，并能回填音乐工作台。
- “工具箱”至少能完成提示词字节检查、纯音乐/音效模板复制和下载健康检查。
- “聊一聊”与“生成内容文档”职责清晰；AI 生成新卡片，手动编辑更新当前卡片。
- 现有 Atlas Cloud MiniMax Music 3.0 / Suno V5 生成、纯音乐/音效约束和下载回归测试不退化。
