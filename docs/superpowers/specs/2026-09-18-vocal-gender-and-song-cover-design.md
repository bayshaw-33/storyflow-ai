# 音乐工作台人声方向与歌曲封面设计

## 目标

- 人声歌曲生成增加“男声 / 女声 / 不限”选择，并让后台 AI 在歌词与 V6 曲风提示词中遵循选择。
- 每条音乐生成候选支持一键生成 1:1 歌曲封面，固定使用 `flux-2-max`，生成后可预览和下载。
- 封面与对应生成任务绑定，刷新、切换项目和进入生成历史后仍可访问。
- 纯音乐和音效继续支持生成封面，但不显示或应用人声性别限制。

## 交互

- 人声歌曲模式显示人声方向选择，默认“不限”。切换到纯音乐或音效时隐藏该选择，并不向音乐任务传递人声方向约束。
- 每条候选操作区显示“生成封面”；已有封面时显示封面缩略图与“下载封面”。生成中按钮禁用并反馈状态。
- 封面生成失败不影响音频播放、重试和删除；错误显示在音乐工作台当前错误区域。

## 数据与接口

- 音频候选返回 `coverUrl`，来源于任务 `result_metadata.cover.storagePath` 的短期签名 URL。
- 新增 `/api/audio/jobs/[jobId]/cover`：
  - `POST` 校验用户、项目和音乐任务归属，调用现有图片 Provider 管线的 `flux-2-max`、`1:1`、单张生成，将结果转存到 `art-assets`，并把存储路径写入任务元数据。
  - `GET` 校验用户和项目归属，为封面生成带下载响应头的短期签名 URL。
- 删除音乐任务时，若存在封面存储路径，先删除 `art-assets` 封面，再删除音频文件、音频资产和任务记录。

## 提示词

封面提示词以任务标题、音乐模式、曲风提示词和有限长度歌词为上下文，并固定要求方形专辑封面、无可读文字、无 Logo、无边框，避免模型生成 UI 或歌词文本。

## 验收

- 男声、女声、不限三种值在新生成与修改请求中可追踪，非人声模式不携带约束。
- 封面请求固定为 `flux-2-max`、`1:1`、单张，并返回持久化的 `coverUrl`。
- 非当前用户、非当前项目或 TTS 任务无法生成/下载封面。
- 全量测试、TypeScript、构建和登录态外页面冒烟测试通过。
