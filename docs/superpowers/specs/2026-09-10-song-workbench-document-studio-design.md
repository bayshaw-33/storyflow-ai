# 歌曲工作台文档创作与生成中心设计

## 目标

将歌曲工作台改为“左侧聊天与文档、右侧生成与试听中心”的工作流，服务歌曲创作、剪辑师纯音乐生成和剪辑师音效生成。桌面端采用黄金分割：左侧 38.2%，右侧 61.8%。

## 已确认的产品决策

- 右侧移除现有歌词、歌词翻译、风格提示词三个大面板。
- 左侧聊天流显示两个独立文档卡片：歌词、Suno V6 曲风提示词。
- 音效需求在聊天流中显示“音效生成描述”成果卡，不纳入歌词或曲风文档体系。
- 每次 AI 生成都会新增文档卡片；旧卡片保留。
- 手动编辑并保存直接更新当前卡片；手动保存不新建卡片。
- 点击文档卡片打开居中的只读预览弹窗，可复制、进入编辑。
- 歌词预览弹窗提供一键翻译；翻译结果只作为临时预览，不创建第三种文档。
- 歌曲生成默认组合最新歌词文档和最新 V6 曲风提示词文档，也允许分别组合历史版本。
- 纯音乐只选择曲风提示词文档；音效只选择音效生成描述卡。
- 右侧采用 Compact Producer：横向大播放器、模型/内容/模式选择、生成按钮、生成历史列表。
- 模型只保留 Atlas 内部的 MiniMax Music 3.0 与 Suno V5；专业生成继续使用已有 Suno 跳转链接调用官网 V6。
- 纯音乐必须在提示词和 API 参数两层禁止 vocals、singing、humming、chanting、choir、spoken word 和 vocal textures。
- V6 曲风提示词使用 UTF-8 字节数，生成、编辑、保存和发送到 Suno 前都必须小于等于 1000 bytes。
- 主题曲 Intro 默认直接进入器乐 hook 或演唱，不使用旁白、念白或 spoken intro。

## 页面结构

左侧为创作对话区，保留聊天输入、附件入口和创作记录。AI 返回内容解析为文档卡片并插入聊天流。卡片显示标题、版本、类型、字节数或摘要、更新时间以及打开入口。

右侧为生成中心。顶部为横向播放器，显示专辑封面、曲名、模型、内容类型、时长、波形、进度和播放操作。下方是内容类型切换、模型选择器、内容版本选择器和主生成按钮。底部是生成历史，支持播放、下载、重试和更多操作。

桌面布局用 CSS grid 的 `38.2fr 61.8fr` 实现；窄屏退化为聊天/结果视图切换，不能让播放器、文档预览或生成按钮溢出。

## 文档交互

预览弹窗默认只读，关闭后返回原页面滚动位置和选择状态。歌词弹窗的“一键翻译”显示加载、成功和失败状态，可复制翻译结果。进入编辑后使用 textarea 或等价编辑表面，保存前校验文档类型和内容；保存成功更新当前卡片并关闭或回到只读预览。

曲风提示词编辑器显示 `currentBytes / 1000 bytes`。超限时显示明确错误，保存、复制、打开 Suno 均不可用，并提供 AI 精简到限制内的操作。自动精简必须保留风格锚点、段落推进、演唱方向、配器、动态、混音和结尾要求。

## 音频生成数据流

聊天文档是专业 V6 目标的创作母版。提交 Atlas 时，根据所选模式和内容卡片生成适配 MiniMax Music 3.0／Suno V5 的内部提示词。歌曲发送歌词与曲风；纯音乐丢弃歌词并加入双层无人声约束；音效发送音效生成描述并标注实验模式。右侧内容选择器必须显式显示当前选中的版本，避免生成时使用不可见的旧内容。

已有的异步提交、轮询、下载、入库和失败重试闭环继续使用。任何 HTML/JSON 错误页、空文件、下载失败、入库失败或超时都必须进入可重试失败状态，不得留下“已排队”幽灵任务。

## 验收标准

1. 桌面端右侧不再渲染歌词、翻译和风格提示词大面板，左右比例为 38.2%／61.8%。
2. AI 生成歌词和曲风时，每次生成新增独立卡片；只修改歌词时只新增歌词卡片。
3. 文档可预览、复制、进入编辑并原卡片保存；歌词可一键翻译且不产生独立翻译卡片。
4. 右侧可分别选择歌曲、纯音乐、音效及其内容来源，并生成历史列表。
5. 纯音乐请求在后台提示词和 provider payload 中均包含无人声约束。
6. V6 曲风提示词在所有入口均不超过 1000 UTF-8 bytes。
7. 现有 Suno 专业跳转入口保留。
8. 目标测试、类型检查、生产构建和 Playwright 关键交互通过。
