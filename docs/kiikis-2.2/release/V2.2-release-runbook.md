## 发布步骤

### 1. 代码与分支

```bash
git checkout main && git pull --ff-only origin main
# 确认 main 含 K22-P0..P6 全部内容：
git log --oneline -1            # 期望 merge: K22-P5 workflow fusion 之后的最新提交
git branch --merged main        # 确认 P0-P5 分支已合并
```

### 2. 迁移应用（Supabase）

按顺序应用 forward-only migrations（只增不改）：

```bash
supabase db push               # 或按 CI 流程执行 migrations
# 应用顺序：...20260828020000 → 20260828030000 → 20260828031000 →
#           20260828040000 → 20260828050000 → 20260828060000
```

应用后执行审计：

```bash
supabase db lint               # schema 检查
node scripts/audit-kiikis-22-migrations.mjs
```

**关键**：migration 为 forward-only，**不回滚**。schema 缺陷只能新增 `20260828*_K22-P6_release_fixes.sql` 之后的 migration。

### 3. 环境变量（Vercel / 部署平台）

Production 必须 fail-closed（值均为 `false` 或未设置）：

```
NODE_ENV=production
NEXT_PUBLIC_USE_FIXTURE=false
NEXT_PUBLIC_USE_KK_FIXTURE=false
NEXT_PUBLIC_USE_SHORT_DRAMA_FIXTURE=false
NEXT_PUBLIC_USE_UNIVERSE_FIXTURE=false
NEXT_PUBLIC_USE_MARKETPLACE_FIXTURE=false
NEXT_PUBLIC_USE_JOB_FIXTURE=false
NEXT_PUBLIC_USE_CREATOR_CENTER_FIXTURE=false
NEXT_PUBLIC_USE_LICENSING_FIXTURE=false
NEXT_PUBLIC_USE_MODEL_FIXTURE=false
# 灰度：V2.2 入口开关（默认关闭；逐级放开）
KIIKIS22_FF_ENTRIES_ENABLED=false
```

**CosyVoice（可选）**：仅服务端 env，不设 key 则配音生成按钮禁用（真实 503）：

```
COSYVOICE_BASE_URL=
COSYVOICE_API_TOKEN=
COSYVOICE_MODEL=
```

### 4. 灰度顺序（Task 6.5 Step 4）

每级至少完整跑六条 smoke 中适用旅程，并检查错误率：

1. **内部账号**：`KIIKIS22_FF_ENTRIES_ENABLED=true`（仅内部邮箱）
2. **小比例创作者**（5%）：观察会话恢复 / 最新输入 / 导入 U1 指标
3. **剧本高频用户**（10–20%）：重点看连续性、候选 Diff、重开恢复
4. **全部用户**：稳定 24–48h 后全量

关闭开关时旧项目仍可读，V2.2 数据不删除（同表同契约）。

### 5. 发布停线条件（任一出现立即停止并回滚 Web）

- 会话丢失（重开消息不完整）
- 历史覆盖（静默 UPDATE/DELETE append-only 数据）
- 跨用户数据访问（RLS 漏洞）
- U1 非原子（finalize 半成功）
- 未授权公开/商业使用（真人声音保护失效）
- migration/audit 失败

## 监控（Task 6.5 Step 2）

| 指标 | 观测点 |
|---|---|
| 创建成功率 | work/version 创建 → finalized 转换率 |
| 会话恢复 | 重开会话消息数 = 上次消息数 |
| 最新输入丢失 | Snapshot last_user_message_id 与输入一致 |
| 静默覆盖 | append-only 表 UPDATE/DELETE 触发告警 |
| Import→U1 | session u1_ready 转换率 |
| Job 动作 | submit/cancel/retry 成功率 |
| Community/Actor 服务 | service_unavailable 频率 |
| Evidence 下载 | 下载成功 + manifest sha256 校验通过率 |
