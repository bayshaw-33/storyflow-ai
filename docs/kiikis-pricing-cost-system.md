# kiikis Pricing Cost System

Internal model assumptions for launch pricing and entitlement risk.

## Draft Script Credit

- 1 Draft Script Credit maps to 1 complete 60-80 episode Chinese draft script.
- Expected model cost assumption: `$0.8-$1.2`.
- Stress ceiling: `$1.5`.

## KK Coins

- 1000 KK coins internal budget: approximately `$1` risk-adjusted model cost.
- Platform GPT and image features consume KK coins.
- User-owned API usage does not consume platform model KK coins; the user pays their own provider.

## Launch Risk Estimates

- Free max estimated cost: `$0.8-$2.1` per fully used free user.
- Elite annual launch gross margin: `48%-62%`.
- Pro annual launch gross margin: `62%-67%`.
- Universe annual launch gross margin: `41%-49%`.

## Launch Discount Formula

```txt
Launch Monthly = Original x 0.6
Launch Annual = Original x 0.6 x 0.8
Launch Annual = Original x 0.48
```

This document is internal only and does not implement billing, checkout, metering, or payment provider logic.
